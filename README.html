The shared correctness core

This is the architectural center of gravity: transport-specific code may reconnect, reset, overflow, suspend, or race, but stale keys must never remain pressed on the console.

1

Canonical state

core/keyboard_state.c

256 usage bits + modifier bits + source error bits. Merges BLE fragments, filters unsupported usages, and detects new presses.

2

Ordered report pipe

core/report_pipe.c

16-slot queue with epochs, sequence numbers, deduplication, overflow recovery, release barriers, resync, and remote-wake latching.

3

USB device adapter

usb/usb_keyboard.c

One report in flight. Owns mount, reset, suspend/resume, HID idle/protocol, LED output, remote wake, acknowledgement, and latency statistics.

Why phase lock exists

The receiver bus and PS5 bus each tick every 1 ms but are unrelated. Core 1 steers the receiver poll to land about 250 μs before the PS5 frame, reducing the chance that a fresh report misses the next console poll.

Pico 2 W: one cooperative loop

tud_task(), the USB adapter, CYW43/BTstack polling, UART recovery, and LED service all run in one foreground execution context.

BLE HOG client lifecycle

STARTING→ UNPROVISIONED→ SCANNING→ CONNECTING→ SECURING→ HIDS_SETUP→ READY
timeout / disconnect / auth failure→DISCONNECTING or CANCELING→BACKOFF↺ approved peer or scan

Security requests bonding + MITM + LE Secure Connections. The first secured keyboard identity is stored in flash; later boots reconnect only to it. UART command forget deletes that approval and bonding record.

What the project promises—and refuses

In scope

  • Ordinary keyboard keys and modifiers
  • Six-key USB boot protocol + rollover
  • Safe reconnect, reset, suspend, and resynchronization
  • Keyboard LEDs received from the console
  • Latency measurement and Feather phase tuning

Intentionally out of scope

  • Mouse forwarding
  • Media / consumer-control reports
  • Logitech HID++ vendor features
  • Adding keyboard support to games that lack it
  • Pairing the LIGHTSPEED receiver (done beforehand on a PC)
